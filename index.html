Google Drive integration

Google Drive is not active until OAuth configuration is completed. This UI is a workflow only.

  1. Use Google Cloud Console to create a project and enable the Drive API.
  2. Create OAuth 2.0 credentials for a web app.
  3. Add redirect URIs such as https://<pages-project>.pages.dev/drive/oauth/callback and http://localhost:8000/drive/oauth/callback.
  4. Keep client secrets on the server, not in frontend source.
  5. Test Drive file access before enabling production use.

Drive sync is not active. Google OAuth and redirect configuration are still required.
