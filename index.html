Google Drive synchronization

Direct Drive backup requires a configured Google OAuth application and Drive integration. This fresh project does not claim that Drive sync is already connected.

  1. Use Download full backup to create a JSON backup.
  2. Upload that file to your Google Drive manually.
  3. On another device, download the backup and use Restore backup.

This manual method is free and avoids storing Google credentials in the website. Automatic cloud sync can be added later with proper OAuth configuration.
